## Becoming a maintainer

Maintainership is granted to contributors who have demonstrated sustained,
high-quality contributions and good judgment. Open an issue or reach out to
an existing maintainer if you would like to be considered.

## Responsibilities

Maintainers are expected to:

- Triage incoming issues and pull requests in a timely manner.
- Review code for correctness, style, and security.
- Cut releases following [SemVer](https://semver.org/).
- Uphold the [Code of Conduct](CODE_OF_CONDUCT.md).
